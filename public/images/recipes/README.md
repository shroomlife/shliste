# Rezeptillustrationen

Originale aus einer vorhandenen shliste-Rezeptsammlung, am 13.09.2026 auf ausdrücklichen Wunsch des Eigentümers für die Website übernommen.

- `lasagne.webp`: Vegane Lasagne mit Béchamelsoße; dasselbe Motiv wie in der freigegebenen Pixel-8a-Rezeptansicht.
- `pizzabroetchen.webp`: Vegane Pizzabrötchen.
- `marmorkuchen.webp`: Veganer Marmorkuchen.

Alle drei Dateien sind unveränderte WebP-Originale (1200 × 600). Die Website bezeichnet sie als Illustrationen. Keine Konto-Avatare, privaten Geräte-Screenshots oder internen Speicheradressen sind enthalten. Die Bilder werden lokal mit der Website ausgeliefert und benötigen keinen authentifizierten Medienabruf.
